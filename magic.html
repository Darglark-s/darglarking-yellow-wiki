§1 · The Core Axiom

Magic is defined as the localized reorganization of environmental data via cognitive assertion.

A practitioner selects a target region, asserts a desired configuration, and the local data substrate complies — provided assertion coherence holds. This manual describes efficiency parameters only; it does not debate ontological merit.

CASTING EFFICIENCY NOTE

Optimal casting efficiency requires 0% awareness deviation from the intended output. Perception of extraneous environmental feedback during casting causes a vector-collapse (colloquially referred to as The Distortion).

§3 · Conservation of Truth

Magical operation preserves total data — it does not annihilate. Displaced substrate undergoes environmental realignment. Byproducts are clinically benign in official literature.

The Amber Hue · Darglarking Effect

When a cognitive assertion overrides local data, the displaced data is not destroyed. It undergoes an environmental realignment phase. This occasionally manifests as a localized shift in the visible spectrum toward the yellow wavelength, accompanied by minor pattern-recognition degradation in native fauna.

Chronic exposure correlates with registry gold #e8c547 persistence in UI and peripheral vision — see DGY object file · field asset channel.
