Authoritative — NULL · Prevention Protocol

Authoritative · NULL principle · Pass 3 implementation

Null Prevention is a sub-protocol within the NULL principle — not a fifth classifier. When luck is high in collapse, null manifests as skeletal bones; when prevention is active, the anchor holds.

Background monitor detects stasis traps (90s unchanged progress) and unwinnable states, then executes a pathway back:

  • Resource injection (wall integrity, null essence, etc.)
  • Session checkpoint reload
  • Recovery shelf restore · fires rtd.backup_restore hook

Arena entity logs: [NULL PREVENTION] Safety Net Active: System Restored to Grounded Baseline.

No local save state becomes permanently negated — the storm went, the lighthouse held.
